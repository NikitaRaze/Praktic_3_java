# Менеджер задач

Практическая работа по Git, вариант 4. Приложение добавляет задачи с необязательным сроком, показывает их нумерованным списком и удаляет по номеру.

## Сборка и запуск

Нужен JDK 8 или новее. Команды для PowerShell запускаются из корневой папки проекта.

```powershell
javac -encoding UTF-8 -d out src/Main.java src/Task.java src/TaskFile.java
java "-Dfile.encoding=UTF-8" -cp out Main
```

В IntelliJ IDEA откройте папку проекта, назначьте JDK, при необходимости отметьте `src` как **Sources Root**, затем запустите `Main.main()`. Рабочая папка конфигурации — корень проекта.

| Команда | Действие |
| --- | --- |
| 1 | Добавить задачу. Введите название и срок в формате ГГГГ-ММ-ДД или нажмите Enter для задачи без срока. |
| 2 | Показать задачи. |
| 3 | Удалить задачу по её номеру из списка. |
| 0 | Сохранить список и выйти. |

При старте приложение читает `tasks.txt` из рабочей папки, а при выходе сохраняет список в UTF-8. Файл с задачами исключён из Git. В каждой строке сначала идёт срок (или пустое поле), затем вкладка табуляции и название.
